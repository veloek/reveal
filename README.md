# Reveal

VSCodium extensions for showing menu button to reveal open file in sidebar.

Will call command __"workbench.files.action.showActiveFileInExplorer"__.

## Installation

1. Clone repo to `~/.vscode-oss/extensions/veloek-reveal`
2. From command palette: "Developer: Install Extension from Location..."
3. Select directory with extension files
